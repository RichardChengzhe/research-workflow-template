%% Required packages in the MAIN file preamble:
%%   \usepackage{booktabs}        % \toprule \midrule \bottomrule

%%   % \usepackage{dcolumn}       % optional: decimal-point alignment
%%
%% CONVENTIONS DEMONSTRATED BELOW
%%   * threeparttable wraps the tabular so the Notes ride with the table.
%%   * Full-width table: tabular*{\textwidth}{@{\extracolsep{\fill}}...}
%%     spreads columns edge-to-edge regardless of how many there are.
%%   * Dense body: \fontsize{10}{12}\selectfont before the tabular.
%%   * Each estimate is TWO lines: coefficient + stars on top, ( t-stat )
%%     on the line below.  *** t-statistics in parentheses, NOT std errors. ***
%%   * Focal (hypothesis) terms come FIRST, then a labeled "Controls" block,
%%     then a \midrule, then FE-indicator rows + N + adj-R^2.
%%   * Thousands use a LaTeX-math brace group: 12{,}345  (renders 12,345).
%%   * Negative numbers use math minus: $-$0.0045  (true minus, not hyphen).
%%   * Stars as math superscripts: 0.0150$^{***}$.
%%   * Distinguish levels from changes in row LABELS: a change/shock variable
%%     is written $\Delta$X (e.g. "$\Delta$[SHOCK]"); an interaction uses
%%     $\times$ (e.g. "[FOCAL] $\times$ $\Delta$[SHOCK]"). Be explicit about
%%     whether a regressor is a LEVEL or a CHANGE -- never leave it ambiguous.
%% =====================================================================
